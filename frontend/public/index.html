      Регистрация сотрудников / Employee Registration

      Режим без считывателя (сейчас у вас так)

      Программа на вашем компьютере не связана со считывателями в офисе, пока поставщик не настроит webhook. Карты без наклейки с UID — это нормально: номер хранится только в чипе карты. Пока связи нет, используйте один из способов ниже.

      1. Способ A (быстро): нажмите «Сгенерировать временный UID», введите имя и фамилию, выберите смену → «Сохранить». После привязки карты замените UID в Edit.
      2. Способ B (если знаете UID): прочитайте UID через приложение NFC Tools (Android) или панель Legacy Reader → вставьте в поле Card UID.
      3. Способ C (когда webhook заработает): сотрудник приложит карту к двери → UID появится в списке «Недавние сканы» или после «Scan Card Now».
      4. После регистрации нажмите Test Entry в таблице — так проверяется посещаемость без двери.
