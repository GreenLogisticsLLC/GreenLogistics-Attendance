# Agent instructions — GreenOS

## Testing / walkthrough artifacts

**Do not create photos, screenshots, screen recordings, or demo videos** unless the user explicitly asks for them in that message.

- Applies to every task and every project context in this repo.
- Do not run GUI/computer-use walkthroughs “for evidence” by default.
- Prefer a short written summary of what changed; use automated/API/log proof when testing is needed.
- Including `/no-test` skips testing entirely when the user wants that.

## Communication

Keep change reports short and direct. No recap fluff.
